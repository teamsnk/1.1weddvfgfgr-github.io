# SNK Design — Premium Animated Website

A responsive static website starter built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For best local testing, use VS Code Live Server.

## Upload to GitHub Pages
1. Extract this ZIP.
2. Upload the contents of this folder to the root of your GitHub repository (make sure `index.html` is at the root).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/(root)`, then save.
6. Wait for the Pages URL to appear.

## Customize before publishing
- Replace the illustrative portfolio cards in `index.html` with actual projects and approved assets from your Figma file.
- Update `hello@snkdesign.studio` in `index.html` and `assets/js/main.js` to your real contact email.
- This is a visual starter inspired by the lime/black/white direction visible in the supplied Figma overview. It is not yet a pixel-perfect export of every Figma frame.
- The contact form uses `mailto:`; it does not store or send messages through a backend.
- Google Fonts are loaded online; the page falls back to system fonts if unavailable.
